## What was built

DCA Guard, project 3 of 5 for QoreChain Build Before Q-Day, Advanced AI Agents, solo, testnet only, in ~/workspace/qorechain/dca-guard.

* Web app: Vite plus React plus TypeScript guard dashboard, near black with one bright amber accent, bold numbers for caps and limits, clear ACTIVE versus PAUSED states.
* Agent engine: separate module `src/agent/dcaEngine.ts` with plain, testable rules in code. It checks pause state, demo message authentication, scoped EVM window, window duration limit, target allowlist, per buy value limit, total spend cap, and max buy count, in that order. A blocked buy pauses the agent.
* Reference contract: `contracts/DcaGuard.sol`, same window, value, total, count, allowlist and pause rules. Deployed on testnet as 0x5f2024c7802d656334d3e5a7315516eae2ae8cb6, see Live testnet status, Nov 15 2026 above. Not audited.
* Featured image: `featured.png`, 1600 by 900 PNG, 62,053 bytes, generated by `scripts/generate-featured.py` with PIL and DejaVu fonts.
* Docs: README.md with the exact problem sentence first, LICENSE (MIT), STORYBOARD.md with five Baheet beats, and this report.
